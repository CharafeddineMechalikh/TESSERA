Run configuration

Generation runs a layer-streamed Qwen2 decoder whose KV cache lives on the workers. Every attention query is evaluated by all workers and merged with an exact float64 log-sum-exp, so the text is produced by the distributed attention path. Weights are streamed per layer, so decoding is much slower than a resident model: about 8–15 seconds per new token on this machine, so the 1000-token default can run for hours unless the model ends the sequence first or you press Cancel.

What this measures

Q/K/V tensors are captured from the pinned Qwen2.5-Coder-1.5B snapshot by an isolated capture process, then replayed through fresh HTTP worker processes that apply the certified omitted-mass pruning protocol. The dense reference is computed locally by the coordinator and is never sent to workers. When generation is enabled, a second worker cluster holds the KV cache and every attention query is evaluated there before the coordinator produces the next token.
