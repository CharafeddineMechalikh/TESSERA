Mathematical Foundation

Multiplicity-corrected softmax & provable omitted probability mass upper bounds

1 Token Multiplicity Score Correction

When token $j$ with value vector $v_j$ is distributed across $c_j$ worker nodes, setting $s'_j = s_j - \log c_j$ ensures that summing over all $c_j$ worker copies recovers the exact global log-sum-exp sum and output vector:

$$\sum_{k=1}^{c_j} e^{s_j - \log c_j} = c_j \frac{e^{s_j}}{c_j} = e^{s_j} \implies Z_{\text{reconstructed}} = Z_{\text{exact}}$$

2 Geometric Cauchy-Schwarz Block Score Bounds

For key block $B$ with precomputed centroid $c_B = \frac{1}{|B|}\sum_{j \in B} k_j$ and radius $r_B = \max_{j \in B} \|k_j - c_B\|_2$, the Cauchy-Schwarz inequality guarantees that for any query $q$:

$$\forall j \in B, \quad s_j = \frac{q^\top k_j}{\sqrt{d_k}} \le U_B = \frac{q^\top c_B + \|q\|_2 r_B}{\sqrt{d_k}}$$

3 Bounding Omitted Mass $p_P$ over Un-retained Unique Tokens

Let $R$ denote evaluated worker blocks and $U_{\text{missing}}$ denote unique tokens with 0 copies in $R$. Using Cauchy-Schwarz upper bounds $U_B$, we construct a tight upper bound $\widehat Z_P$ over missing unique tokens:

$$\widehat Z_P = \gamma_{\text{safe}} \cdot \sum_{j \in U_{\text{missing}}} e^{U_{B(j)}}, \qquad p_P \le \frac{\widehat Z_P}{Z_R + \widehat Z_P}$$

Assuming bounded value vectors $\|v_j\|_2 \le V_{\max}$, the $\ell_2$ output error is strictly certified by:

$$\|O_{\text{full}} - O_R\|_2 \le 2 V_{\max} p_P$$

The algorithm dynamically retains blocks ordered by $U_B$ until $2 V_{\max} p_P \le \epsilon_{\text{tol}}$, offering rigorous error control.
